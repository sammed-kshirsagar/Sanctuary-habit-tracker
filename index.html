How to Use Sanctuary

Guide to your daily habit & sleep spread

1. Daily Habits (Left Grid)

Each vertical column represents a daily habit, and each row represents a day of the month (Y-Axis). Click any checkbox to mark a habit complete for that day.

2. Customizing Habits (Up to 10)

Click the Habits button at the top to rename, reorder, remove, or add new habits with category colors.

3. XY Sleep Consistency Graph (Right Grid)

The X-Axis tracks hours slept from 0 to 10. Click an intersection to plot your sleep hours—points connect automatically to visualize consistency.

4. Cloud Save & Share

Use the Cloud Save button in the header to generate a shareable save code or backup your tracker as a file.
